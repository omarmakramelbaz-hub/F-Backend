# تجربة فسخانستا ERP

[افتح التجربة على GitHub Codespaces](https://codespaces.new/omarmakramelbaz-hub/F-Backend/tree/codex/fasakhansta-erp-foundation-20260930?quickstart=1)

1. افتح الرابط بحساب GitHub الذي يستطيع الوصول إلى المستودع، واضغط **Create codespace** (أو **Resume** إذا أنشأته سابقًا).
2. انتظر تجهيز البيئة وتشغيل التطبيق تلقائيًا. من إشعار المنفذ 8080 اضغط **Open in Browser**؛ وإذا لم يظهر الإشعار، افتح **Ports** ثم رابط المنفذ **8080**.
3. اختر **أدمن إداري** واضغط **ابدأ التجربة**. يمكنك الرجوع لرابط **تغيير حساب التجربة** لاختيار المالك أو مدير المنصورة.

هذه نسخة من كود ERP الموجود في طلب المراجعة، تعمل على Laravel 8 وPHP 8.2 وقاعدة SQLite مستقلة. جميع الأرصدة والأسماء والطلبات بيانات مصطنعة. لا تُقرأ إعدادات أو قواعد بيانات التشغيل ولا تتصل التجربة بالدفع أو الإشعارات.

## ماذا تجرّب؟

| الخطوة | الإجراء | النتيجة المتوقعة |
|---|---|---|
| الموردون والمشتريات | فاتورة جديدة للمورد التجريبي: 2 كيلو فسيخ خام × 210 جنيه إلى المخزن المركزي | زيادة المخزون 2 كيلو وزيادة مستحق المورد 420 جنيه |
| التصنيع | اختر الوصفة التجريبية ومخزن المنصورة، عدد الوصفات 1 والناتج الفعلي 1 | خصم 1.2 كيلو خام وعلبة واحدة وإضافة كيلو منتج جاهز |
| الحسابات والكاش | سجّل سداد 420 جنيه للمورد التجريبي | انخفاض الكاش ومستحق المورد بالقيمة نفسها |
| الموظفون | سجّل حضور موظف تجريبي اليوم | حفظ الحضور وإظهاره في الكشف |
| الصلاحيات | بدّل إلى مدير المنصورة | يرى مخزون وموظفي فرعه، ولا يستطيع دخول الحسابات المركزية |
| المالك | افتح الحسابات والصلاحيات وأنشئ حسابًا تجريبيًا | يمكن استخدام البريد وكلمة المرور الجديدة في شاشة الدخول العادية |

بيانات التجربة محفوظة عند إعادة فتح نفس Codespace. تشغيل الإعداد مجددًا لا يعيد التهيئة ولا يمسح تغييراتك. لإنشاء تجربة جديدة من الصفر، أنشئ Codespace آخر؛ لا توجد إعادة ضبط تلقائية.

منفذ Codespaces خاص افتراضيًا: أبقه **Private**. الدخول السريع إلى أدوار التجربة مخصص لهذه البيئة فقط ويعتمد على حماية دخول GitHub إلى المنفذ. هذه ليست آلية دخول للإنتاج. لا تستخدم بيانات عملاء أو كلمات مرور حقيقية.

طلبات التطبيق عينات للعرض؛ POS/KDS وربط الاستهلاك التلقائي لم يُنفّذا بعد. التجربة لا تختبر ضغط العمليات المتزامنة على MySQL؛ تلك الاختبارات منفصلة في CI. تغييراتك هنا لا تُنشر على السيرفر ولا تنشئ حسابًا حقيقيًا في نظام التشغيل.

بعد الانتهاء، أوقف Codespace من [صفحة Codespaces](https://github.com/codespaces) لتوفير رصيد التشغيل. التشغيل خاضع لحصة وتسعير Codespaces في حسابك؛ إنشاء البيئة يبدأ من حسابك ولا يُنشئ هذا الرابط بيئة قبل الضغط على زر الإنشاء.

## التشغيل المحلي للمطور

يلزم PHP 8.2 مع SQLite وmbstring وXML وComposer 2. من جذر المستودع:

```bash
bash tests/erp_runtime/demo/install.sh
bash tests/erp_runtime/demo/start.sh
```

افتح `http://localhost:8080`. الحالة المحلية موجودة في `tests/erp_runtime/demo/state/` المستثنى من git وخارج جذر الويب. الموجّه يخدم ملفات الواجهة المحددة ومسارات ERP فقط، ولا يمرر أي طلب إلى تطبيق الإنتاج. فحص HTTP المتكامل (ينشئ عمليات تجريبية إضافية ويحتاج المنفذ 8080 غير مشغول):

```bash
python3 tests/erp_runtime/demo/smoke.py
```
