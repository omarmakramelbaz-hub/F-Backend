# Filtered monthly employee net total

The employee tracking screen gains an eighth summary card, **إجمالي صافي المستحقات**, and a total aligned with the net-entitlement column in the table footer. It uses the selected entitlement month and all matching employees authorized by the existing branch, search, job and shift filters, across every result page.

The service sums the existing `period(...).net_cents` values as integer cents and formats the result with the established money formatter. It retains the current salary, part-time, deductions, advances and closed/paid snapshot rules, including negative balances. The listing reuses page statements when calculating the total. This is a display/read calculation; it does not close payrolls or transfer funds.

The root installer validates pinned source blobs, preflights the incremental source transforms, and backs up their original files privately before applying them. It also ensures the previously requested branch wallet-phone exception is installed, while retaining central profile management and Owner-only bonuses.
